# Bright Future Institute

A small static website for an education institute. It contains a home page, a course catalog, and a contact page.

## Project files

- `index.html`: home page with responsive navigation, hero with animated statistics, features, featured programs, admission steps, testimonials, a call to action, footer, and an application dialog.
- `course.html`: course catalog with six sample course cards.
- `contact.html`: institute contact information and a contact form.
- `style.css`: shared stylesheet currently used by the home page. The course and contact pages have their styles embedded in their HTML files.

## Preview

Open `index.html` in a browser. Use the navigation links to move between the home, courses, and contact pages. No build step or package installation is required.

## Demo limitations

- The application form displays a confirmation message but does not submit or store an application.
- The contact form has no configured destination or submission handling.
- Course search, category links, pagination, and enrollment links are placeholders and do not filter, navigate, or enroll.
- Course images and the Inter font on the course and contact pages are loaded from external services and require an internet connection.
